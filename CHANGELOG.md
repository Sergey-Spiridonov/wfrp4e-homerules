# Журнал версий

## 1.14.2 — 2026-10-10

- Черта «Броня» отводит травму: урон по графе самой травмы засчитывается при любом
  порядке за столом. Если травму уже бросили, при отводе снимаются выпавшие пункты
  здоровья, а карточка травмы в чате зачёркивается и на лист больше не кладётся.
  Если травму уже перенесли на лист, она снимается с листа (пункты система сняла
  при переносе). Если ещё не бросали — ведущий бросает по таблице и берёт только
  пункты, как в правиле убийцы чудовищ. «Отменить» возвращает снятые пункты.

## 1.14.1 — 2026-10-04

- Домашнее правило «Убийца чудовищ: отвод травмы за пункт удачи» по умолчанию
  выключено. В мирах, где его включали в настройках, оно остаётся включённым.

## 1.14.0 — 2026-10-04

Первая открытая версия.

- Справка `/правило` — по желанию: по умолчанию выключена, работает с любой
  службой поиска с тем же запросом `GET /search` (описание в README).
- Заплатка меню правой кнопки в чате по умолчанию выключена: в wfrp4e 10.0.3
  дефект починен.
- Цитаты правил в коде заменены пересказом со ссылкой на раздел книги.

## 1.13.0 — 2026-10-04

- Рывок из меню токена: проверка атлетики (+20), линейка перемещения прибавляет
  бег + уровень успеха до конца раунда; переброс и +1 УУ пересчитывают.
- Девятнадцатая длань Воланса: развеивание силой воли без навыка «Язык
  (магический)».

## 1.0–1.11 — 2026-09

- Убийца чудовищ отводит травму за пункт удачи; Разрубающее портит черту
  «Броня»; черта «Броня» отводит травму; порча и починка черты с листа.
- Заплатка меню правой кнопки в чате для wfrp4e 10.0.0.
- Заклинания по своим папкам и школам; поиск на вкладках листа.
- Справка в чате `/правило`; сводка по партии для ведущего.
